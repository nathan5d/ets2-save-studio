# Changelog

## 1.0.0-beta.1 — 2026-11-15

First public beta release candidate.

### Added

- Desired total balance editor with current-balance loading, regional currency preview and live change indicator.
- Truck and Coaches progression editing.
- Classic truck skill editing.
- Configurable ETS2 data folder.
- Transactional writes with automatic backups and external-change detection.
- Backup Manager with validated restoration and interrupted-operation recovery.
- Light and dark themes.
- Brazilian Portuguese and English localization.
- Portable and per-user Windows x64 distribution options.

### Compatibility

- Windows x64.
- Euro Truck Simulator 2 1.62.x.

### Important

- Steam Cloud must be disabled before editing.
- ETS2 must be closed during editing and restoration.
- This is an independent, unofficial tool with no affiliation to SCS Software, Valve or Steam.
